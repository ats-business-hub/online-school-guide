春から副業でWeb制作を始める前に、学習範囲と届出を確認する

公開日（サイト原稿）：2026-11-21　記述の基準日：2026-11-21

広告（PR）について。本記事には、A8.net、バリューコマースなどのアフィリエイト（成果報酬型広告）リンクが含まれます。リンク経由で申し込みや利用があった場合、運営者が紹介料を受け取ることがあります。リンクはテキストのみです。就職、収入、税負担の軽減、投資の利益、最安値などを保証するものではありません。各サービスの対象条件・成果地点・料金は、申し込み前に公式ページで確認してください。

▶ 比べる点と窓口の例は「次のステップ」へ（広告を含みます）

春から、本業のあとでWebサイトやランディングページの制作を受けたいと考え、先にオンライン講座で学ぶ人は少なくありません。講座で制作の手順を学ぶことと、取引先を得ること、収入を得ることは別です。本記事は、春に向けて学習を始める前に、学ぶ範囲、公開の仕方、勤め先の副業の定め、税金の届出を確認するための案内です。案件の獲得、収入、継続的な仕事は保証しません。特定の講座やサーバーの推奨でもありません。

Webスキルの個別講座と学び放題の違いはWebスキル講座と学び放題の違い、修了後の作品公開は講座修了後に、ポートフォリオサイトを公開する手順、動画編集講座を見る場合は動画編集スクールを選ぶ前の確認点を見てください。期間と総額の見方はリスキリング講座の期間と総額は、週あたり時間と延長費から見る、新年度の仕事が忙しくなる前のペース確認は新年度の仕事が忙しくなる前に、学習の曜日と休会条件を確認するにあります。

先に分けること

  1. 学びたい範囲。 見た目のデザイン、HTMLやCSS、ホームページ作成ツール、写真や動画、見積もりと契約、公開後の更新のうち、講座が扱う範囲と、自分が春までに必要だと考えている範囲は一致しないことがあります。カリキュラムに契約実務や税務が含まれない場合、別途、公式の行政案内や専門家で確認することになります。
  2. 作品の公開場所。 講座の課題を、閲覧期限のある受講サイトの中だけで見せるのか、自分で管理するURLで見せるのか。公開手順は講座修了後に、ポートフォリオサイトを公開する手順を見てください。公開すれば仕事が来ることは保証しません。
  3. 勤め先の副業の定め。 民間企業でも、就業規則で副業の届出や禁止が書かれていることがあります。公務員など、法律や規則で制限がある職種もあります。当サイトは、個別に副業できるかを判断しません。就業規則と、必要なら勤め先の担当部署、所管の案内で確認してください。
  4. 税務の手続き。 給与所得者が、給与以外の所得の合計で一定の金額を超える場合など、所得税の確定申告が必要になることがあります。申告が不要な場合でも、住民税の申告が別に必要になることがあります。開業届を出すかどうかは、事業として行うかの判断を含み、この記事では示しません。金額の基準や、自分の申告の要否は、国税庁の案内や税務署、税理士などへ確認してください。当サイトは税務助言ではありません。申告漏れがないこと、節税できることは保証しません。

学習を申し込む前に、講座へ確認すること

  • 制作物の著作権と、ポートフォリオへの掲載可否。他者の素材や、いまの勤務先の情報を使わない
  • 案件紹介や転職支援がある場合、対象条件、追加料金、成果の定義。成果は保証されません
  • 公開サーバーや独自ドメインの手配が、講座の料金に含まれるか、自分で契約するか
  • 春（4月前後）に仕事の時間が減る見込みがあるとき、視聴期限と休会条件が合うか

口コミの見方はオンラインスクールの口コミを申し込み前に確認するときの見方を見てください。収入や案件数の体験談は、当サイトでは未確認とし、契約条件より優先しません。

広告（PR）。制作スキルを学ぶ講座の一例として、動画編集スクールのクリエイターズジャパン、発信やSNSのスキルを確認する無料カウンセリングの一例としてSONOMAMAがあります。講座の課題や作品を、自分で管理するURLで公開する場所の一例として、レンタルサーバー エックスサーバーがあります。いずれも一例であり、推奨ではありません。講座の受講やサイトの公開が、案件の獲得、就職、収入につながることは保証しません。料金、契約期間、掲載の条件、解約条件は公式案内で確認してください。最新情報は公式サイトでご確認ください。

春から始める場合の、時期の確認

「春から副業」と決めても、学習、作品の公開、届出、最初の依頼は同じ月から始まりません。先に、学習に使う月と、対外的に引き受ける月を分けて書いてください。新年度の本業が忙しくなる前に契約だけ結ぶと、期限切れや延長費が出ることがあります。急ぎの申し込みが有利かは書きません（キャンペーンの期限は未確認）。

チェックリスト

  • 講座が扱う範囲と、自分が必要だと考えている範囲を書き分けた
  • 作品をどのURLで見せるか、著作権と機密の制約を確認した
  • 勤め先の就業規則で、副業の届出や禁止の有無を確認した（職種により法令の制限もある）
  • 所得税と住民税の申告、開業届の要否を、行政の案内または専門家に確認する項目にした
  • 視聴期限と、4月以降の本業の時間を照合した
  • 収入や案件の獲得を、申し込みの前提にしていない

よくある質問

講座を修了すれば、春から仕事を受けられますか。

受けられることは保証しません。修了と、取引先の有無、契約、納品の責任は別です。勤め先の定めと、税務の手続きも、受け始める前に確認してください。

無料の公開スペースだけでも、副業の準備になりますか。

足りるかどうかは、見せ方と、自分が引き受ける仕事の種類で違います。無料スペースの可否は講座修了後に、ポートフォリオサイトを公開する手順の説明も参照してください。公開自体が仕事を約束するものではありません。

所得が少ないうちは、何も届出をしなくてよいですか。

しなくてよいかは、所得の種類と金額、自治体の扱い、事業として行うかで違います。当サイトは要否を判断しません。「少ない」という印象だけで済ませず、国税庁の案内や税務署などで確認してください。
